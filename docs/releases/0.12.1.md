# WordPress Manager 0.12.1

Publishes the site-page review pass and unified local-copy dialog from main.
Site tools include rename, compare, backups and explicit delete choices; active
transfers and their recovery controls remain visible in Activity. Pull and Make
a local copy share the same source-specific dialog. Refresh options include
translations and gentle request pacing.

Deploy the matching Zoer host and DDEV bridge before installing this package.
The host supplies the ownership, single-user migration and site operations;
installing the plugin alone does not migrate Zoer or update a WordPress site.
Existing site IDs, connections, catalogs and transfer receipts are preserved.

Release validation: frozen dependency install, type check, tests, production
build, manifest/package validation and deterministic release packaging. Live
installation and smoke-check results are recorded in the host's dated rollout
report. WordPress-site transfers and core/extension changes require their usual
separate review; publishing this package does not perform them.
