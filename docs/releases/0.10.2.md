# WordPress Manager 0.10.2

This release adds a reusable, reviewed workflow for publishing selected plugin and theme code from a local WordPress copy to its linked site. It also supports refreshing live data into an existing local copy while preserving selected development files, saved designs and local configuration.

- Choose individual plugin/theme folders, compare files and review the exact changes before publishing.
- Code-only exports omit the database and media; destination settings, authentication configuration and active extensions remain in place.
- Dry-run, staged review, activation, Finish and retained recovery backups are available through the normal transfer interface.
- Refresh local data without silently replacing development code or the saved design records selected for preservation.
- Existing site links, transfer history and repository development links remain available.

The matching Zoer host changes in PR 27 are required for database-free DDEV exports and the disabled-plugin Enable control. See [code publication](../code-publication.md) and [repository development](../repository-development.md).

## Install or update

Use Zoer’s Plugins interface with the GitHub release source `ahzs645/zoer-plugin-wordpress-manager`, tag `v0.10.2` or latest. Stage the package, review the upgrade and apply it, then enable WordPress Manager. Existing GitHub-channel installations can use **Check for updates**. A manually installed development package must select the GitHub release source once to follow that channel.
