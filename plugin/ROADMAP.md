# WordPress follow-up work

The current implemented features and limitations are recorded in [README](../README.md). Do not treat the former extraction roadmap as a missing-feature list.

Remaining architecture work includes approval-aware write operations in the generic adapter broker, stronger multi-replica coordination for file-backed host jobs, additional provider import verification, and supported backup formats beyond the current single-site Updraft contract. None of these is implied by installing the independent native interface.
